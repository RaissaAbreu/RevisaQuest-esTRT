# PDFs de questões

Coloque aqui os arquivos PDF com as questões (Certo ou Errado).

Cada questão deve trazer: enunciado, gabarito (Certo/Errado), comentário,
matéria e incidência (Altíssima, Alta, Média ou Baixa).

Para enviar pelo GitHub (navegador): abra esta pasta no repositório,
clique em **Add file → Upload files**, arraste os PDFs e clique em **Commit changes**.
